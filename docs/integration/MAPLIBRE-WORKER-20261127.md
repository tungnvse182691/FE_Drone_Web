Base09f0f72903881e2416fc7c457ddc59fc6f7aad53, branch hoang. FE-only, local commit; no push/PR, backend/database/config/CSP/permission changes. Existing styles, route colors/names/markers and navigation left unchanged.

## Reproduction and exact cause

Installed MapLibre6.11.2, Vite6.4.3 from existing lockfile. Read installed src/util/web_worker.ts, config.ts and dispatcher.ts. MapLibre6 defaultWorkerUrl uses import.meta.url and constructs a sibling maplibre-gl-worker.mjs URL dynamically. Vite cannot discover/emit that dynamic sibling as a build dependency. Source worker also imports maplibre-gl-shared.mjs, so simply copying one worker file or using a plain ?url asset would not reliably package its dependencies.

Before fix, actual workspace dev5173: worker http://localhost:5173/node_modules/maplibre-gl/dist/maplibre-gl-worker.mjs, type module, HTTP200 text/javascript, no worker failure. Dev excludes maplibre-gl optimization and can access its sibling modules.

Before fix, actual build preview5181 from workspace dist (not temporary baseline): worker http://localhost:5181/assets/maplibre-gl-worker.mjs, type module. No worker asset existed in dist/assets. Network response200 text/html (SPA fallback index), then worker error and exact UI/Console message: Worker failed to load. Check that the worker URL is correct.

Captured document CSP and CSP-Report-Only headers: absent on dev and preview; no CSP meta either. No evidence CSP blocked worker. No CSP relaxation performed. Other Console auth401 before login and duplicate Case key warnings are separate, not hidden or relabeled worker errors.

Console/Network captures outside Git: artifacts/map-worker-20261127/dev-before.json, preview-before.json, dev-after.json, preview-after.json. Only map URLs/status/headers and diagnostic errors captured; no credential/token/cookie output. Login uses existing authorized account in isolated browser memory, no business decision writes.

## Fix and coverage

src/utils/maplibre.ts imports maplibre-gl/dist/maplibre-gl-worker.mjs?worker&url and sets MapLibre setWorkerUrl once at shared helper initialization. Vite now bundles the worker plus shared dependencies, emits hashed worker asset and uses Vite-resolved URL in both dev/build. Workers remain enabled, errors remain visible; no error handler removed or swallowed. No package upgrade, manual file copy, style or backend/proxy/Vite configuration change.
